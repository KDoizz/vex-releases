# Vex

Baixe vídeos e áudios de mais de 1000 sites, com legendas criadas e traduzidas pelo próprio app.

## Download

Baixe o **`Vex Setup.exe`** da [versão mais recente](https://github.com/KDoizz/vex-releases/releases/latest) e execute.
Depois de instalado, o Vex avisa sozinho quando há uma versão nova.

Requer Windows 10 ou 11 (64 bits).

---

Este repositório guarda só os instaladores e as notas de cada versão. O código-fonte do Vex é privado.
